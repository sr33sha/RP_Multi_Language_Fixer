# RP_Multi_Language_Fixer
Ever come across less-intelligent models butchering non-english sections of roleplays sometimes? This might help.

<img width="1084" height="907" alt="Screenshot 2026-09-23 233747" src="https://github.com/user-attachments/assets/e4fb895c-5929-4ad8-b1fb-08f082557a7d" />

Use a high-intelligence model just to fix the non english sections, costs way less than a full request obviously.

Use your own api key which you can link to HTML through a .txt file. Choose any Openrouter model and bam! All done.

Comes with both native script and roamnized versions.

Current languages include: Bengali, Hindi, Arabic, Spanish, Hungarian, Russian, Mandarin and Chinese.

You can always add your own custom languages by forking and editing HTML.
