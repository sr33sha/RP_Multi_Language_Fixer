# RP_Multi_Language_Fixer
Ever come across less-intelligent models butchering non-english sections of roleplays sometimes? This might help.

<img width="1084" height="907" alt="Screenshot 2026-09-23 233747" src="https://github.com/user-attachments/assets/e4fb895c-5929-4ad8-b1fb-08f082557a7d" />

Use a high-intelligence model just to fix the non english sections, costs less than a full request obviously.

Use your own api key which you can link to HTML through a .txt file. Choose any Openrouter model and bam! All done.

Comes with both native script and roamnized versions.

Current languages include: Bengali, Hindi, Arabic, Spanish, Hungarian, Russian, Mandarin and Chinese.

You can always add your own custom languages by forking and editing HTML.

<img width="1019" height="871" alt="Screenshot 2026-09-23 234540" src="https://github.com/user-attachments/assets/3058061e-2954-43e4-a4e0-d78d45cc3766" />


Also comes with an additional Cinex Fixer HTML for a fictional language I made up called Ci'Nex. It is basically a full reversal of English, word for word not entire sentences. Didn't know it'll make LLMs suffer this much, hence the fixer. This one is baked with its own rules and needs no api key. Also, it only fixes the Ci'nex parts that models mess up, so run it through this and it'll become correct. It doesn't touch normal English or any other language.
