Language Fixer

Multilingual text correction — paste, correct, keep everything else untouched
Runs through OpenRouter with your own key and whichever model you trust for the language you pick below. When a line has an English translation in parentheses right after it, the original text (native script or romanized) is treated as unreliable and completely replaced with a fresh translation of that English gloss — not just spell-checked. Content with no gloss nearby gets corrected into proper script as a best effort. Everything else in the passage — narration, English dialogue, formatting — is returned exactly as written. You get both a native-script version and a romanized version back, since you can't always read one of them.

Keeps the key out of the HTML itself. Put your key in a small .txt in the same Drive folder as this file, then use "load key from .txt" on whichever device you're on — no retyping, and the key never has to live inside a file you might reshare.
Any OpenRouter model slug. Use whichever model you trust most for this language.
